# Joshua Kahlbaugh — Personal Website

Personal site for **Joshua Kahlbaugh**: about, hobbies, resume/experience, skills, and contact.

## Stack

- [Next.js](https://nextjs.org/) (App Router)
- [React](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- TypeScript

## Content sources

Real bio, experience, hobbies, and contact details were taken from Josh’s public sites and resume:

- https://joshuakahlbaugh.pages.dev/
- https://minimalist-portfolio-website-orcin.vercel.app/
- Public resume PDF hosted on those sites

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
